Casos prácticos · Funcionalidades pequeñas

Estima funcionalidades pequeñas y bien delimitadas. Para cada caso, identifica la técnica más apropiada, establece los supuestos necesarios y explica brevemente cómo realizarías la estimación.

Caso 1 · Recuperar contraseña

Un usuario solicita recuperar su contraseña. El sistema recibe su correo, valida que la cuenta exista y envía un enlace temporal para restablecerla.

Caso 2 · Registrar usuario

Un visitante diligencia nombre, correo y contraseña. El sistema valida los datos, verifica que el correo no esté registrado y crea la cuenta.

Caso 3 · Consultar detalle de producto

El usuario selecciona un producto y el sistema muestra nombre, descripción, precio, disponibilidad e imagen.

Caso 4 · Registrar una reserva

El usuario selecciona una fecha y una franja horaria disponible. El sistema valida la disponibilidad y registra la reserva.
