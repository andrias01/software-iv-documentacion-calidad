2. Caso: Plataforma de matrícula universitaria

  • R1. El sistema permitirá matricular asignaturas y mostrará la confirmación lo antes posible.
  • R2. Un estudiante podrá matricular una asignatura si cumple los prerrequisitos definidos.
  • R3. La matrícula podrá modificarse hasta las 11:59 p. m. del último día.
  • R4. La pantalla informa que las modificaciones están permitidas hasta las 6:00 p. m.
  • R5. El sistema almacenará los datos necesarios y otros datos relevantes del estudiante.
  • R6. Si no hay cupo, el sistema podrá permitir la matrícula para que el estudiante intente asistir.
  • R7. El sistema cumplirá las políticas institucionales aplicables, aunque no se identifican.
