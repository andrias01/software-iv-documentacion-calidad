2. Caso: Aplicación de transporte universitario

  • R1. El estudiante podrá reservar un cupo de transporte con una anticipación razonable.
  • R2. Las reservas para la ruta Norte se cerrarán a las 5:00 p. m. del día anterior.
  • R3. El módulo móvil muestra que se cierran a las 10:00 p. m.
  • R4. Si el vehículo está lleno, el sistema permitirá confirmar la reserva.
  • R5. El sistema notificará al estudiante si su reserva fue confirmada.
  • R6. Las notificaciones deberán enviarse rápidamente.
  • R7. La aplicación utilizará controles de acceso institucionales, sin especificarlos.
