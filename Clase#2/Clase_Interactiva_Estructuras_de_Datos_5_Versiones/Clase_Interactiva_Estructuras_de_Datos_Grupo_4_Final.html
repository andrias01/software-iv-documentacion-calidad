🔁 4C. Recursividad paso a paso: función de Ackermann · 20 puntos

La función de Ackermann es un ejemplo clásico de recursividad. En este ejercicio se trabajará el trazado de llamadas paso a paso, sin ejecutar el programa.

A(m,n) =
  n + 1,                         si m = 0
  A(m-1,1),                      si m > 0 y n = 0
  A(m-1, A(m,n-1)),              si m > 0 y n > 0

Paso 1 · Caso base

¿Cuánto vale A(0,5)?

Paso 2 · Segundo caso

Si m > 0 y n = 0, ¿a qué llamada se transforma A(1,0)?

Paso 3 · Resolver una llamada

Complete la cadena: A(1,1) → A(0, A(1,0)) → A(0, ___)

Paso 4 · Resultado

¿Cuál es el resultado de A(1,1)?

Paso 5 · Trace la recursividad

Para A(1,2), escriba las llamadas principales que observa antes de llegar al caso base.

Reto de análisis

Explique por qué Ackermann es un buen ejemplo para estudiar recursividad y qué característica hace que el número de llamadas crezca rápidamente.
